Routine in-use replacement is NOT designed in
The primary cartridge must survive the intended mission. Circuit hot-swap or bypass while actively supporting a patient is a Rev-B problem unless DARPA explicitly requires it.

Consequence for the FMEA: cartridge failure is mitigated by detection + conservation mode + escalation — not by field replacement. This must be stated in the proposal so a reviewer does not assume an unqualified hot-swap capability.
Mission load on top of the device: cartridge 2.22 kg + O₂ + batteries + blood + drugs. The cartridge is a consumable, never counted in device mass.
