## THE 7 HIGHLIGHTS (the founder's picks from the image)
1. **grill-with-docs** — interviews you BEFORE the implementation plan + builds the domain model (CONTEXT.md + ADRs inline!)
2. **code-review** — reviews the architecture + the diff against the standards/spec, not just the syntax!
3. **diagnosing-bugs** — the systematic debugging workflow (no random guessing!)
4. **research** — investigates primary sources via a background agent → the cited Markdown in the repo!
5. **grill-me** — the relentless interview until the plan has no weak spots (the stateless version!)
6. **handoff** — compresses an entire coding session into a clean brief for the next agent!
7. **writing-great-skills** — the repeatable skill-crafting discipline!
