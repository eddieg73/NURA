# Notion Second Brain — Design Doctrine (2026-08-29)

The Notion workspace is the **human-facing mirror** of this Obsidian vault (source of truth)
and the GitHub `vault` branch. Treat it as a **personal app interface**: highly visual, never
cluttered. Balance aesthetics with ruthless organization.

## The 6 techniques

### 1. Container Hack (Callout Blocks)
`/callout` → subtle background (Gray/Brown). Remove the default emoji. Drag page links, task
lists, inline databases INSIDE the callout → distinct colored zones. No floating links.

### 2. Visual Navigation (Gallery Views)
Never a plain text list for main nav. New database → **Gallery View** → Card Preview → **Page
Cover**. Add aesthetic covers → a clickable Pinterest-style grid.

### 3. Cohesive Icons & Covers
Icons: Notion's built-in minimalist library (middle tab), ONE color, or custom SVG line-art.
Covers: custom Canva headers 1500×500 matching the palette; Unsplash as fast fallback.

### 4. Master Columns & Dividers
`/col` → 2/3/4 columns. "Boss" layout = narrow LEFT for nav + wide RIGHT for active daily tasks.
`/div` → subtle dividers between topics.

### 5. Strict Color Palettes (Rule of Three)
One main text, one accent (headers), one muted background (blocks). Constrained palette
(muted earth tones, or dark + single neon accent) = professional. Every color = chaos.

### 6. Third-Party Widgets
Live embeds from Indify.co / Apption / WidgetBox: clocks, weather, Google Calendar, progress
bars. Match colors to theme, paste URL, "Create embed".
