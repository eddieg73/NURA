# 100M Sales Team — 8-Role AI Sales System (founder directive 2026-08-15)

A sales-team prompt system. Each persona = ONE job, used as a BUSINESS FRAMEWORK (never copied voice):

| Role | Framework | Job |
|---|---|---|
| Alex Hormozi | Offer creation | Fixes the offer (value stack, grand slam) |
| Gary Vee | Attention | Fixes content + attention (jab/jab/hook) |
| Grant Cardone | Activity/urgency | Fixes sales activity + follow-up |
| Jordan Belfort | Objections | Fixes objections + closing (straight-line) |
| Dan Kennedy | Direct response | Fixes copy |
| Russell Brunson | Funnel | Fixes customer journey |
| Seth Godin | Positioning | Fixes differentiation |
| Tony Robbins | Execution | Fixes standards + action |

## The 6-step playbook
1. **Build the team** — the role-definition prompt.
2. **Fix the offer** — 6 questions: weak / generic / unclear / hesitation / stronger value / one-sentence rewrite.
3. **Fix content angles** — 20 ideas, each with hook + angle + objection handled.
4. **Fix objections** — top 10 no's, each with real fear + better answer + pre-selling content idea.
5. **Fix the funnel** — traffic → content → lead magnet → offer → follow-up leak audit; fix first + simplest improved funnel.
6. **Fix the copy** — 10 hooks, 3 short posts, 3 CTAs, 1 follow-up, 1 pinned comment.

## Rules
- Frameworks only — never copy anyone's exact voice.
- Each role attacks from its ONE angle; then combine into one stronger plan.
- Operationalized as Hermes skill `sales-team-8-roles`.
- Paperclip ownership: second product directive (fitness suite = product 1).
