## 2. IP / Source Doctrine (NON-NEGOTIABLE — never disclose)

1. **Public releases / announcements / filings brand our advances under NURA's OWN proprietary names.** We NEVER disclose the open-source software we build on.
2. **Open-source software names, links, and attribution are referenced ONLY in INTERNAL documents** (vault, internal Notion, internal/private GitHub) — never in anything public (marketing, PR, the Reg A/offering circular, customer-facing, public repos).
3. The Reg A already describes the system **by capability, not product/vendor** (the proprietary-integrated-process framing) — this is the public-safe posture. Keep it.
4. **We own the process/system** (the integration, orchestration, agent, memory, flywheel) — that's the IP. The components are implementation details, internal-only.
5. **Never rip closed-source/proprietary AI** — open weights + permissive OSS only, behind the license gate; open-source stays internal.
6. **Public release cadence** — announce advances (new capability releases) publicly under the NURA brand; never attribute to the underlying OSS.
