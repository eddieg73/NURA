## 2. IP / Source Doctrine (NON-NEGOTIABLE)
1. Public releases/announcements/file brand advances under **NURA's OWN proprietary names** — never the underlying open-source software.
2. Open-source references are **internal docs only** (vault, internal Notion, private GitHub) — never public (marketing, PR, Reg A, customer-facing, public repos).
3. Reg A describes by **capability, not vendor** (proprietary-integrated-process framing) — keep it.
4. We own the **process/system** (integration, orchestration, agent, memory, flywheel). Components are internal-only.
5. Never rip closed-source/proprietary AI — open weights + permissive OSS only, behind the license gate.
6. Public-release cadence under the NURA brand; never attribute to the OSS.
