## 3. DESCRIPTION OF BUSINESS

### The Proprietary Integrated Process (the IP thesis)
NURA's IP is **the integrated process**, not any single component — the way Ford's assembly line was the patent, not the individual parts. NURA owns the **orchestration + integration + agentic workflow** that turns disparate capabilities into ONE white-labeled practice-operating process, delivered under each provider's own brand. The system is described here by **capability**, not by third-party product names; the underlying process and architecture are the subject of patent applications (provisional pending), and the components are assembled behind NURA's proprietary orchestration layer.

### Capabilities (white-labeled for each provider/practice)
- **Practice CRM** — patient acquisition, pipeline, follow-up (proprietary, MCP-wired core; swappable connector).
- **Clinical Data Engine (EMR)** — chart, encounter, orders, e-prescribing, FHIR interop to destination EHRs.
- **AI Voice Agent** — 24/7 conversational receptionist: answer, book, qualify, collect.
- **Multichannel Patient Comms** — SMS/voice/chat/email patient messaging + unified inbox.
- **Social Proof / Reputation** — reviews, testimonials, sentiment.
- **Payments (PCI)** — credit-card processing, plans, financing (NMI partnership).
- **Clinical Interoperability (HL7/FHIR)** — ADT/ORU/orders to/from external EHRs via NURA-Bridge.
- **Agentic AI Harness** — the NURA agent runtime (skills, memory, delegation, cron, MCP tool layer) driving the whole process; sovereign local-AI lane for offline/no-credit operation.
- **Revenue Cycle / Billing Intelligence** — claims, eligibility, denial logic (human-validation gate).

### Embodied, Wearable & Vision (assistive — added)
- **Drones** — EMS/medical logistics delivery (meds/antivenom/blood) + aerial overwatch (observe/relay/alert, never weaponized).
- **Robotics** — clinic/hospital logistics + (early) humanoid concepts; assistive only.
- **Computer Vision** — on-device perception: form/pose (wellness), scene, landing-zone, instrument.
- **Wearable (OMI, Bluetooth)** — patient context/vitals capture, ambient care documentation.
- **Medics' Eyewear / Body-Cam (facial recognition, on-device)** — assistive identification to (a) match a patient to records at the point of care (local-only, HIPAA-sensitive, consent-gated) and (b) cross-check a criminal/missing-person/watchlist for **paramedic & first-responder safety** (threat awareness on scene). Runs on the edge device (local embeddings, no cloud), with biometric-privacy/consent and public-safety-law gates (state biometric laws, 4th-Amendment limits).

### Core Technology Infrastructure (the proprietary engine)
NURA agent harness (skills/memory/delegation/cron/MCP) · sovereign local-AI lane (offline inference) · automated workflow orchestration · clinical interop (HL7/FHIR) · on-device computer vision · GPU inference · Qdrant-class vector memory · zero-trust architecture · HIPAA compliance controls · PCI payment rails · Docker-on-VPS fleet · immutable audit logs.
